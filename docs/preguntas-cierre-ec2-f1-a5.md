## 2. ¿Qué es un componente?
Es una parte que programamos para ser independiente y reutilizable en la interfaz.
## 3. ¿Por qué los componentes comienzan con mayúscula?
Para que react los distinga de las etiquetas html.

## 4. ¿Qué diferencia existe entre HTML y TSX?
tsx escribe estructuras similares a html dentro de typescript, y html pues ya lo conocemos. 
## 5. ¿Para qué se utiliza className?
Para asignar clases css a los elementos.
## 6. ¿Qué son las propiedades o props?
Datos que un componente padre envia a uno hijo. 
## 7. ¿Cómo ayuda TypeScript a validar las propiedades?
Verifica tipos y detecta errores.
## 8. ¿Cuál es la responsabilidad de App.tsx?

Para facilitar la organizacion, reutilizacion y mantenimiento de los mismos.
